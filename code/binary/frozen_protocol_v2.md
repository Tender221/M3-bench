## Frozen definitions and comparison protocol

For each view and joint condition c: `e_mkc = qualify(image_single(c)) AND qualify(text_single(c))`, `F_mkc = e_mkc AND NOT outcome(joint(c))`. Strict41 requires clean+all40singles under the qualification axis. Three views: Task (qualify/outcome bit4), Semantic (bit1/bit1), Semantic-on-fixed-Task (bit4/bit1).

Populations: own (per-model mask) and common4 (intersection of the four qualification masks, separately per exact cell or strict41). Common4 is a fixed-roster matched control, not a deployment-independent qualification. Report retained roots/images and eligible counts, denominators and source composition.

Primary summaries (fractions, also report component counts):

1. `JSR = 1 - sum(F)/sum(e)` corresponding-single joint success retention. Empty support=NA. `JFR=1-JSR` is the same metric, not an independent contribution. `ECR=sum(e)/(N*400)` is mandatory companion support coverage. Also retain full-population clean/single/joint accuracy.
2. `JSS = mean_k I(all400 joint outcomes pass)` over the fixed strict41 mask. It complements existing affected-question coverage; report average strict41 joint accuracy as context, recognizing JSS counts questions and event density counts conditions.
3. `TGR5 = mean of largest ceil(.05*V) cell failure rates F_c/E_c` across V cells with original eligible count>=30 (the support rule is numerical stability policy, not a significance threshold). Fixed eligible cell set per cohort; recompute tail membership within that set for bootstrap. If no valid cell,NA. Sensitivity: tail fractions .01,.05,.10 and minimum support10,30,50, all exported rather than chosen after results.
4. Supplementary hotspot exceedance curve `H(tau)=mean_c I(F_c/E_c>tau)` on the same valid cells, tau grid0..1 in .001 increments, with preselected illustration thresholds .005,.01,.02,.05. This is actual rate coverage, not old WNA bootstrap support. Its integral equals the macro mean rate (up to discrete plotting quadrature); no independent AUC contribution claim. Export macro mean and micro pooled gap separately.

Baselines computed on the same labels: clean/single/joint accuracy; clean-normalized relative joint drop `(clean-joint)/clean` (MMI-style) and joint/clean retention; minimum full-root joint-cell accuracy. Do not imply reimplementation of a published benchmark's complete score without the exact published definition. Old WNA/Excess results/CI are not reused.

Matched-case analysis: for each of the four models, on common4 strict41 roots, compute each pair's16-cell mean accuracy, fraction of roots passing all16 and per-cell failures. ## Pre-production clarifications v2

These mathematical and completeness clarifications were accepted before Task2 implementation or production; they do not depend on observed rankings. Frozen v1 remains archived.

- JSR is exactly pooled joint accuracy on the eligible root-cell records. If restricted to strict41, it equals ordinary strict41 mean joint accuracy. JSS is exactly one minus affected-question coverage on the same complete suite. These are interpretable endpoints, not independent algebraic discoveries. TGR and H are recoverable from the conditional cell-rate map; the added information is qualification and cross-condition root alignment.
- Task is the primary view. Enumerate all1200 pair-of-pairs per view separately (3600 across three views), export every candidate with inclusion/selection flags, and choose the frozen top3 within each view. Never pool views for selection.
- Bootstrap universe is all1065 original image IDs, with1065 draws with replacement per replicate. One seed17 draw matrix is shared across models and views. Use95% percentile intervals at [.025,.975] with NumPy linear quantiles. Record valid draw IDs; differences use valid same-draw contrasts.
- TGR retains the original valid cell set. If any originally valid cell has zero eligible support in a replicate, that entire TGR replicate is NA. Do not shrink its cell set or interpolate. Report invalid replicate counts. If clean accuracy is zero, normalized drop/retention are NA.
- Common cell eligibility is the AND of all four own eligibility masks; every model's common numerator uses that exact common mask. The separate common strict41 mask is an intersection of root qualifications. ECR denominator stays1500*400; retained strict roots/images are reported separately. Export per-cell image support as well as roots; support30 counts roots, not independent images.
- Source-equal sensitivity is limited to ratio endpoints JSR/JSS and full accuracy summaries, averaging the frozen three-source ratios with NA for any empty source. Do not define an unplanned source-equal tail score. Export micro pooled failure rates over all eligible cells and over valid cells separately, so filtering and weighting effects are distinguishable.
- Only unconditional marginal maps fail to identify JSR; conditional cell maps with denominators determine JSR/TGR/H. Even same-cohort per-cell maps do not determine cross-condition suite survival. Observed matched cases are explicitly16-cell pair-suite survival, not two different400-cell JSS values. Tail uses ceil(q*V) discrete cells, not interpolated fixed-mass CVaR. Semantic-on-fixed-Task success cannot decrease relative to Task on the same masks; validate this identity.
