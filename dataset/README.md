# Dataset Note

This release package includes dataset preprocessing scripts, but does not bundle processed benchmark JSONL files by default.

Please prepare or regenerate the required OpenQA-style JSONL files in your own environment before running the full pipeline.

Examples referenced by the README, such as:

- `./dataset/OK-VQA/okvqa_val_openqa.jsonl`

should be treated as user-prepared paths unless you decide to add those files manually later.
